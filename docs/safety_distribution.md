# 安全境界と配布チェックリスト

## 実装上の境界

- 対象: 保存済み牌譜、保存済みスクリーンショット、自作Rust Simulator、サービス運営者と参加者が明示的に許諾した入力元での友人間研究。
- 非対象: 許諾が確認できないオンライン対局中の助言、画面キャプチャ、対局中の通信解析、非公開APIへの追加要求、入力注入、自動打牌。
- 雀魂Chrome拡張は牌譜閲覧画面だけを対象とし、ユーザーがボタンを押した時に既に受信済みの牌譜応答をローカルdecodeする。対局画面では解析・送信しない。
- `OfflineFrameLab` は指定ディレクトリのPNGだけを読む。画面取得APIを持たない。
- Reviewer APIはGameStateを解析するだけで、外部サービスへ接続しない。WebSocketの `authorized_external_adapter` 宣言は接続元による表明であり、運営者の許可を代替しない。
- 通常EncoderはOracle/山/他家手牌を明示的に拒否する。
- WebSocketはloopbackでのみ起動し、ブラウザOrigin、1メッセージ容量、観測者、可視性、単調増加連番を検査する。

## 公開前に所有者が決める事項

1. プロジェクト本体のライセンスと著作権者表記。現時点では未決定なので、配布可能とは判定しない。
2. 使用データの取得条件、再配布可否、匿名化、削除依頼手順。
3. モデルカード（学習データ、ルール、評価局数、信頼区間、既知の偏り）。
4. Python/Rust/Node依存のNOTICE・ライセンス一覧とSBOM。
5. 牌画像・スクリーンショット・サービス名やロゴを含めないことの確認。
6. macOS/Windows/Linux用署名、アップデート経路、脆弱性報告窓口。

本書は法的助言ではない。特定サービス由来データを公開・配布する前に、最新の利用規約と権利関係を配布主体が確認する。

## 雀魂についての確認記録（2026-10-18）

公開中の[雀魂利用規約](https://dmg.mahjongsoul.com/terms_of_service)には、友人戦であれば外部リアルタイム補助を利用できるという明示的な例外を確認できなかった。友人全員の同意と、サービス運営者による許可は別の条件である。許可の有無が不明なまま雀魂へ接続するadapterは本リポジトリの対象にしない。

本体に実装する雀魂用リアルタイム機能は、正規化済み観測の受信契約、許可記録の必須化、
共通GameEventへの変換、read-only解析配信、保存状態・保存イベントのリプレイに限定する。
雀魂クライアントの通信・画面を取得するcollectorは含まない。

実際に接続・配布する前に、用途、データ取得方法、リアルタイム候補表示の有無、友人戦限定であることを明記し、公式問い合わせ先で書面の確認を得る。許可された範囲が判明した場合だけ、その範囲をテスト可能なadapter要件として固定する。

## 天鳳牌譜

天鳳公式マニュアルでは、一般麻雀への応用を目的とした牌譜使用は問い合わせが必要で、競合製品への開発・応用には使用できないとされている。したがって天鳳牌譜の自動収集機能は実装せず、天鳳由来の人間datasetは明示許可を記録したprovenance manifestがなければ学習処理で拒否する。
