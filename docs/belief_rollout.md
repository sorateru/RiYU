# 公開情報Belief Rollout

`BeliefRolloutSearch` は、不完全情報下で合法手を比較する短時間探索器です。通常の `GameState` に含まれる公開情報と観測者の手牌だけを入力とし、相手の実手牌や実際の牌山順は使用しません。

## 処理

1. 観測者の手牌、河、副露、ドラ表示牌を136枚から除く。
2. 河、副露、リーチ、巡目から相手ごとのテンパイ確率と想定打点を推定する。承認済みV2モデルが指定された場合は、時系列Transformerの聴牌率・待ち分布・局収支予測を事前分布に使う。
3. 物理的な残り枚数を守りながら、相手3人の手牌と生牌山をサンプリングする。
4. リーチ者はテンパイ手に近づくよう制約付きで手牌を生成し、待ち牌を厳密シャンテン計算から求める。
5. 既存の一手評価で上位となった候補について、同じ候補世界を使って数巡先まで進める。
6. 和了、放銃、他家ツモ、シャンテン進行を集計し、推定点数を既存評価へ加える。

既定値は12サンプル、3巡先、上位4候補です。候補間で同じ未知牌サンプルを共有するため、別々の牌山を使う場合より比較時の分散を抑えています。局面JSONから乱数seedを決めるため、同一局面の結果は再現可能です。

## 現在の限界

- V2モデル未指定時の相手モデルは、公開情報を使うヒューリスティックである。
- V2のスモークcheckpointは配線確認用であり、独立評価・較正・Arena承認をまだ行っていない。
- ロールアウト内の相手の手変わりと鳴きは簡略化している。
- 待ち判定は形の完成を使い、すべての候補世界で役の有無を完全判定していない。
- 探索期待点は実測で較正されておらず、厳密な点数期待値ではない。
- 通常の和了点・放銃点精算はRustシミュレーターに存在するが、任意の途中局面を秘密情報付きで再開する機能はまだ接続していない。

探索に失敗した場合は、最終持ち点予測、シャンテン、受け入れ、教師Policyからなる従来の一手評価へ自動的に戻ります。

V2のデータ契約と学習手順は [sequence training](sequence_training.md) を参照してください。
