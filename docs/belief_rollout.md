# 公開情報Belief Rollout

`BeliefRolloutSearch` は、不完全情報下で合法手を比較する短時間探索器です。通常の `GameState` に含まれる公開情報と観測者の手牌だけを入力とし、相手の実手牌や実際の牌山順は使用しません。

## 処理

1. 観測者の手牌、河、副露、ドラ表示牌を136枚から除く。
2. 河、副露、リーチ、巡目から相手ごとのテンパイ確率と想定打点を推定する。承認済みV2モデルが指定された場合は、時系列Transformerの聴牌率・待ち分布・局収支予測を事前分布に使う。
3. 物理的な残り枚数を守りながら、相手3人の手牌と生牌山をサンプリングする。
4. `StatefulParticleFilter` を使う場合は、公開draw/discard/call/doraイベントごとに各粒子を遷移する。模倣Policyの `P(action | sampled hand, observation)` で重みを逐次更新し、ESSが閾値を下回ったときだけ系統resamplingする。Policyに見せるのは当該相手自身の仮想手牌だけで、他の仮想手牌と牌山は見せない。
5. リーチ者はテンパイ手に近づくよう制約付きで手牌を生成し、待ち牌を厳密シャンテン計算から求める。
6. 既存の一手評価で上位となった候補について、同じ重み付き粒子集合を使って数巡先まで進める。
7. 各粒子でRustの厳密な役・符・翻・支払いを計算し、和了、相手別放銃、他家ツモ、他家間横移動、流局、シャンテン進行を重み付き集計する。短期探索内で終局しない質量は流局と混ぜず「未解決」とする。
8. ロールアウト内でも他家の手牌・赤牌・待ちをツモと打牌ごとに更新する。リーチ後はツモ切りに固定する。

既定値は12サンプル、3巡先、上位4候補です。候補間で同じ未知牌サンプルを共有するため、別々の牌山を使う場合より比較時の分散を抑えています。局面JSONから乱数seedを決めるため、同一局面の結果は再現可能です。

## 現在の限界

- V2モデル未指定時の相手モデルは、公開情報を使うヒューリスティックである。
- V2のスモークcheckpointは配線確認用であり、独立評価・較正・Arena承認をまだ行っていない。
- ロールアウト内の他家打牌は厳密牌効率ベースで、鳴きと相手の降り方策はまだ簡略化している。
- 裏ドラ表示牌は未知のため、リーチ和了の厳密点は公開済み情報だけの下限寄りになる。
- 探索期待点は実測で較正されておらず、厳密な点数期待値ではない。
- 任意の途中局面からRust Simulator自体を完全再開するのではなく、PythonロールアウトからRust点数計算境界を呼び出す方式である。

探索に失敗した場合は、最終持ち点予測、シャンテン、受け入れ、教師Policyからなる従来の一手評価へ自動的に戻ります。

V2のデータ契約と学習手順は [sequence training](sequence_training.md) を参照してください。
